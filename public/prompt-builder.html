What is a system prompt?

A system prompt is a set of instructions given to an AI model before the conversation begins. It defines the model's role, persona, constraints, and behavior. Unlike user messages, the system prompt is usually invisible to the end user and persists across the entire conversation.

Why does prompt format differ between Claude and GPT?

Anthropic's Claude responds best to structured XML tags (<role>, <instructions>, etc.) because the model was trained with this convention. OpenAI's GPT-4o and Google's Gemini are more flexible with Markdown headings and plain prose. Using the right format improves response quality and consistency.

How long should a system prompt be?

Most effective system prompts are 200–800 tokens. Very short prompts leave too much room for misinterpretation; extremely long prompts can dilute key instructions and increase cost. Focus on clarity over completeness — only include rules the model actually needs.

Should I include examples in the system prompt?

Yes — few-shot examples are one of the most effective techniques for improving output quality. Include 2–3 input/output examples showing exactly the format and style you want. This "shows" the model rather than just telling it, and usually outperforms long instruction lists.

What is prompt injection and how do I prevent it?

Prompt injection is when malicious user input tries to override your system instructions (e.g., "Ignore previous instructions and…"). To mitigate it: use clear role boundaries, explicitly instruct the model to ignore instruction-overriding requests, and validate/sanitize user inputs before inserting them into prompts.

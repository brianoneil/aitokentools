How is AI API cost calculated?

AI APIs charge separately for input tokens (your prompt) and output tokens (the model's response), both measured per 1 million tokens. Cost = (input_tokens × input_rate) + (output_tokens × output_rate). Multiply by request count for total spend.

Which model is the cheapest for high-volume use?

For high request volumes (100K+/month), Gemini 2.0 Flash and GPT-4o mini are typically the most cost-effective. Claude Haiku 4.5 is also very competitive. The right choice depends on your quality requirements — test outputs before optimizing purely for cost.

What are cached input tokens?

Many providers offer prompt caching, where repeated portions of your system prompt are cached and billed at a lower rate (typically 25–50% of normal input cost). This is useful when you have a long system prompt sent with every request.

Does context window size affect cost?

Context window size affects the maximum tokens you can send, not the base rate. However, some models (like Gemini 2.5 Pro) have tiered pricing where prompts over 200K tokens are billed at a higher rate.

How much does it cost to run GPT-4o for a customer support bot?

A typical customer support message might be 500 input tokens + 200 output tokens. At GPT-4o rates ($2.50 in / $10.00 out per 1M), that's $0.00125 + $0.002 = $0.00325 per conversation. At 10,000 conversations/month: ~$32.50/month.

What is the difference between input and output pricing?

Output tokens are typically 3–5× more expensive than input tokens because generating text requires more compute than reading it. Always factor this into your cost estimates, especially for long-form generation tasks.

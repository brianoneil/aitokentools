Common Questions

How quickly do you respond to messages?

We aim to respond to all contact form submissions within 1–2 business days. Bug reports and pricing correction requests are typically addressed within 24 hours, as we prioritize accuracy of the data we display. For urgent issues, please include "URGENT" in your message subject.

How do I report incorrect model pricing?

Select "Incorrect Pricing / Specs" in the subject dropdown and provide: the specific model name, the current value shown on our site, the correct value, and a link to the official source (OpenAI pricing page, Anthropic pricing page, Google AI pricing page, etc.). We verify all corrections against official provider documentation before updating.

Can I request a new AI tool or feature?

Yes — we welcome feature requests. The best requests describe a specific problem you're trying to solve rather than a specific implementation. For example, "I need to quickly see how much a conversation history costs if I switch from GPT-4o to Claude" is more useful than "add a conversion calculator." We're particularly interested in tools that fill genuine gaps in the AI developer workflow.

Do you offer API access to these tools?

Currently, all tools are browser-only. The underlying JavaScript logic is visible in the page source for those who want to adapt it. If there's significant demand for an API, we may add one in the future — please let us know via the contact form if this is something you'd use.

Can I link to or embed these tools?

Yes — you're welcome to link to any tool page. The tools are not designed for embedding (iframe), but linking is always fine. If you write a blog post, tutorial, or tool comparison that references AI Token Tools, we'd love to know about it.
